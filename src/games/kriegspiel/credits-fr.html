Le Jeu de la guerre a été conçu par Guy Debord, qui en a déposé le principe en 1965 ; il l'a publié avec Alice Becker-Ho (Le Jeu de la guerre : relevé des positions successives de toutes les forces au cours d'une partie, 1987).

Les règles suivies ici sont celles de Debord, lues dans la traduction anglaise parue chez Atlas Press (A Game of War, traduction de Donald Nicholson-Smith). Les points qu'elles laissent ouverts suivent l'interprétation de Kriegspiel, l'adaptation numérique du Radical Software Group (Alexander R. Galloway), dont le texte des règles est publié sous licence Creative Commons BY-NC-SA.

Aucun de ces textes n'est reproduit : les pages de règles de ce module ont été rédigées pour Jocly. Les projets libres pykrieg et a-game-of-war (tous deux sous GPL-3.0) ont été consultés pour comparaison ; aucun code n'en est repris.
