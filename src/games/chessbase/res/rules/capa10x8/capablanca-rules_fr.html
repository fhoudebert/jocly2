Différences avec les échecs orthodoxes

Se joue sur un échiquier de 10x8 cases, avec 2 nouvelles pièces :

  • Le Chancelier : se déplace et capture comme un Cavalier + une Tour

  • L'Archevêque : se déplace et capture comme un Cavalier + un Fou

Position initiale Carrera

Position initiale Capablanca

Position initiale Gothic

Position initiale Janus

Roque :

  • Capablanca, Gothic, Bird : le roi se déplace de trois cases
  • Carrera : pas de roque
  • Embassy : le roi se déplace de trois cases vers la tour
  • Ladorean : le roi se déplace de deux cases vers la tour
  • Janus : le roi se déplace jusqu'à la position initiale de la tour
  • Schoolbook, Univers, Grotesque : le roi se déplace de deux cases ou plus vers la tour
