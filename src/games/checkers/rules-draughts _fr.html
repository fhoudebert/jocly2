Dans toutes les variantes de dames, les règles suivantes s'appliquent :

  • Les joueurs jouent à tour de rôle en déplaçant une pièce
  • Les pièces peuvent se déplacer vers une case vide adjacente
  • Une pièce adverse adjacente peut être capturée en sautant par-dessus celle-ci (ce qui implique que la case suivante soit libre)

  • Lorsque cela est possible, plusieurs captures peuvent être effectuées durant le même tour (avec la même pièce)

Aux dames internationales, les règles supplémentaires suivantes s'appliquent également :

  • Le plateau et la position initiale sont les suivants :

  • Les pièces se déplacent uniquement sur les cases noires
  • Les pièces simples ne peuvent se déplacer que vers l'avant, sauf lors d'une capture
  • Les pièces promues, appelées dames, peuvent se déplacer le long de toute diagonale
  • Après une capture, une dame peut s'arrêter sur n'importe quelle case disponible de la diagonale après la pièce capturée (à condition que les cases traversées soient libres)
  • Les Blancs commencent
  • La prise est obligatoire
  • Les pièces capturées sont retirées après que toutes les captures ont été effectuées
  • Si un joueur doit choisir entre plusieurs séquences de captures, il doit choisir celle qui capture le plus grand nombre de pièces adverses
  • Si une pièce atteint la dernière rangée pendant une séquence de captures, elle n'est pas promue, sauf si la capture se termine sur la dernière rangée
  • Un joueur qui ne peut effectuer aucun mouvement perd la partie
